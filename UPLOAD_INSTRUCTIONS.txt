RockBlockBot v4.4.1 - HELD TOUCH + BOARD ENTRY EXPERIMENT

1. Extract ZIP. Copy its project contents into your existing GitHub Desktop repository.
2. Keep hidden .git and .github folders from your old clone.
3. Commit, Push origin, then open GitHub Actions > Build debug APK.
4. Install the produced APK over your old Blockbot app.
5. Share single app (Rock Block Saga). PREVIEW and inspect cyan tile counts.
6. Tap NEXT MOVE for ONE correct piece; watch that it MOVES ONTO THE BOARD,
   unlike the v4.4 attempt that moved only 42px up in the tray.
7. Shadow must match the green target twice before release. If tracking fails
   or Android cancels, STOP, inspect the game, and send the full report.
8. Do not assume a held gesture succeeded merely because Android accepted it.

Android build and real-world shadow alignment remain unverified locally.

2. GitHub Desktop > Repository > Show in Explorer.
3. Copy CONTENTS of RockBlockBot-v4.4 into the existing clone; replace matching files.
4. Preserve .git and .github folders (the existing Actions workflow builds your APK).
5. Commit, Push origin, then wait for Build debug APK; install APK.
6. Share SINGLE APP -> Rock Block Saga; PREVIEW, inspect all numbered tile markers.
7. NEXT MOVE ONLY for correct shapes. The app will hold the piece, look for
   the game's same-color translucent shadow, correct, and only release after
   two shadow alignment checks. Otherwise it tries to return to tray.
8. Wait up to 30 seconds; if no VERIFIED, STOP and send full report.

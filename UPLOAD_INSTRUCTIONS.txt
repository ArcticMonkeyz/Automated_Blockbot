RockBlockBot v2.4 - update existing GitHub repository

1. Extract this ZIP on your PC.
2. Open GitHub Desktop -> Repository -> Show in Explorer.
3. Copy everything INSIDE the extracted v2.4 folder into the repository root. Replace matching files.
4. Keep .git and .github untouched. Do not nest an extra v2.4 folder.
5. In GitHub Desktop enter: "Blockbot v2.4 drag calibration".
6. Commit to main, then Push origin.
7. Wait for the GitHub Actions build to turn green.
8. Download its APK artifact ZIP, extract app-debug.apk and install it on your Pixel 7 Pro.

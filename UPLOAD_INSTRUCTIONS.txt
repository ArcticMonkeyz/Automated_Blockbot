Update the existing repository https://github.com/ArcticMonkeyz/Automated_Blockbot

1. Open the extracted RockBlockBot-v2 folder.
2. Upload its `app` directory and root `README.md` to the existing repository, REPLACING existing files at the same paths. GitHub's normal Upload files interface may reject overwriting existing paths; the easiest reliable method is GitHub Desktop or Git CLI. Alternatively, use GitHub web editor to update individual files.
3. Keep your existing .github/workflows/build-apk.yml (it already built v1).
4. Commit to main and inspect Actions.

This package intentionally contains NO hidden .github folder.

Blockbot v2.1 update (GitHub Desktop)

1. Extract this ZIP on your PC.
2. Open GitHub Desktop > Repository > Show in Explorer.
3. Copy everything INSIDE the extracted folder into your cloned repository.
4. Choose Replace existing files. DO NOT delete .git or .github.
5. GitHub Desktop: Summary = "Blockbot v2.1 piece recognition"; Commit to main; Push origin.
6. GitHub > Actions > successful build > Artifacts > download the APK ZIP.
7. Extract app-debug.apk and install on your Pixel 7 Pro.
8. Run a game frame and compare the three piece shapes with the game.

RockBlockBot v4.0.1 - Kotlin compile hotfix

1. Extract RockBlockBot-v4.0.1-build-hotfix.zip.
2. In GitHub Desktop, open your existing repo (Repository > Show in Explorer).
3. Copy the CONTENTS of the extracted RockBlockBot-v4.0.1 folder into the repo,
   replacing matching files. Do not delete .git or .github.
4. Commit 'v4.0.1 fix BoardRecognizer compile' and Push origin.
5. Open the GitHub Actions 'Build debug APK' run. Install the APK only after it succeeds.

This corrects .first/.last calls on a Kotlin List and updates the app version.
The existing solver, movement calibration, and recognition logic are unchanged.

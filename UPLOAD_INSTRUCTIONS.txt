1. Extract this ZIP on your PC.
2. Open GitHub Desktop > Repository > Show in Explorer for ArcticMonkeyz/Automated_Blockbot.
3. Copy EVERYTHING INSIDE the extracted RockBlockBot-v2.5 folder into the cloned repository root.
4. Choose Replace files; do NOT delete .git or .github in the existing repository.
5. In GitHub Desktop, commit with summary: Blockbot v2.5 guided multi-move solver
6. Push origin. GitHub Actions builds app-debug.apk and packages it as an artifact ZIP.
7. Install the new APK on your Pixel 7 Pro. If Android reports an update signature conflict, ask for guidance before uninstalling because app settings may be lost.
8. In game: PREVIEW > NEXT MOVE > wait for VERIFIED > PREVIEW again. STOP if UNVERIFIED.

Rock Block Bot v3.9
===================
1. Extract ZIP and open its RockBlockBot-v3.9 folder.
2. Open your current clone via GitHub Desktop > Repository > Show in Explorer.
3. Copy all contents of the extracted folder into that clone and replace matching files.
4. Do not delete .git or .github. Keep the existing .github/workflows/build-apk.yml.
5. GitHub Desktop > commit "v3.9 per-piece calibration" > Push origin.
6. GitHub Actions > Build Debug APK > install the resulting APK.
7. Single-app capture; preview all detected pieces; verify one move at a time.

Rock Block Bot v3.0 - Placement alignment test

1. Extract RockBlockBot-v3.0-placement-alignment.zip.
2. In GitHub Desktop select your Automated_Blockbot repository.
3. Repository -> Show in Explorer (opens the cloned repo directory).
4. Copy the extracted source files into that existing directory. Replace matching files.
5. Do not delete .git or .github (the existing build workflow lives there).
6. Commit: Blockbot v3.0 placement alignment calibration
7. Push origin and use the APK from the GitHub Actions build artifact.
8. Open the updated app, share only Rock Block Saga, and check X/Y are auto-corrected.
9. PREVIEW first; one NEXT MOVE only if the preview is accurate. Send landed-piece screenshot and Last placement check.
10. If the game has only 1-2 real unused pieces because of the previous test, tap RESUME 1/2 PIECES before preview.

The new one-cell offset is a test correction based on one observed placement.
